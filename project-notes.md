# Project Notes

This repository demonstrates Git best practices for managing a DevOps project.

## Git Workflow

- Repository initialized with Git.
- Feature branches used for development.
- Pull Requests used before merging.
- Changes merged into the development branch.
- Development branch merged into the main branch.
- Version tags created for releases.

## Branches

- main
- dev
- feature/documentation
