# Task 2 - Jenkins CI/CD Pipeline

## Objective

Implement a Jenkins pipeline to automate Docker image creation.

## Tools Used

- Jenkins
- Git
- GitHub
- Docker
- Windows

## Steps Performed

1. Installed Jenkins locally.
2. Configured Git in Jenkins.
3. Created a Pipeline Job.
4. Connected the GitHub repository.
5. Used a Jenkinsfile stored in the repository.
6. Built the Docker image through Jenkins.

## Outcome

- Jenkins pipeline successfully executed.
- Docker image built automatically.
- Source code managed through GitHub.
