# Task 1 - GitHub Actions CI/CD Pipeline

## Objective

Create a CI/CD pipeline using GitHub Actions to automatically build and push a Docker image.

## Tools Used

- GitHub
- GitHub Actions
- Docker
- Docker Hub
- Node.js

## Steps Performed

1. Created a Node.js sample application.
2. Added a Dockerfile.
3. Created a GitHub Actions workflow.
4. Configured Docker Hub credentials using GitHub Secrets.
5. Triggered the workflow on every push to the main branch.
6. Verified that the Docker image was successfully pushed to Docker Hub.

## Outcome

- Automated CI/CD pipeline implemented.
- Docker image built automatically.
- Docker image pushed successfully to Docker Hub.
