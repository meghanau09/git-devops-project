# Task 3 - Terraform with Docker

## Objective

Provision a Docker container using Terraform.

## Tools Used

- Terraform
- Docker
- Git
- VS Code

## Steps Performed

1. Installed Terraform.
2. Configured the Docker provider.
3. Pulled the required Docker image.
4. Created a Docker container using Terraform.
5. Verified the container was running.
6. Destroyed the infrastructure using Terraform.

## Outcome

- Infrastructure successfully provisioned.
- Docker container managed through Infrastructure as Code.
- Terraform state generated successfully.
